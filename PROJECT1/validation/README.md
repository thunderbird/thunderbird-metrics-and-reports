# Volume validation — BigQuery vs repo vs aaq-scraper

> Validating *detection* rather than volume? See
> [`detector-backtest-bitdefender-2025-08.md`](detector-backtest-bitdefender-2025-08.md)
> — a known real incident (Bitdefender update, 11–14 Aug 2025) back-tested
> against the committed spike CSVs.


Cross-checks the desktop support-question counts this repo derives (from the
aaq-scraper) against the **SUMO BigQuery ground truth**, after the full-history
backfill surfaced a sustained volume decline (issue **#67**, discovered in #65).

## Verdict: the decline is REAL

BigQuery matches this repo's Project 1 feature counts **exactly for 41 of 43
months (0.0% divergence)**; overall gap **1.0%**, essentially one month. The
2025→2026 halving is present in the authoritative SUMO data — **not a scraper
artifact**. So the spike-report trend lines can show it without an asterisk.

- Monthly: **1,436 (Jul 2025) → 724 (Jun 2026)**.
- Yearly (BQ): 2023 ≈ 12.1k, **2024 ≈ 15.4k, 2025 ≈ 15.2k, 2026 ≈ 5.2k** (partial,
  through ~Jul 4 → ~9–10k annualized).
- The open *why* question (release stability vs support moving to Connect / Matrix
  / Reddit) is a product/support-strategy investigation, tracked in #67.

### Only two divergences (neither undermines the verdict)
- **2023-11** — aaq-scraper coverage gap: captured only **17 of 30 days**
  (BQ 1,308 vs 796). This is the entire 1.0% overall gap. Optional: re-scrape the
  13 missing days to make history perfectly clean.
- **2026-07** — partial-month timing (BQ export ran mid-day Jul 4); negligible.

## Files
- `bq-desktop-questions-by-month.sql` — the BigQuery query (no API access → run in
  the console, export CSV). Filters: `product = 'thunderbird'` (desktop),
  `is_spam = FALSE`, `COUNT(DISTINCT question_id)`, UTC-month bucket.
- `bq-desktop-questions-by-month-2023-01_2026-07.csv` — the exported ground-truth
  counts (run 2026-07-04).
- `desktop-questions-yoy.png` — year-over-year chart (one line/year), generated by
  `scripts/project1_volume_yoy_chart.py`.

## Refreshing
1. Run `bq-desktop-questions-by-month.sql` in the BigQuery console; export CSV over
   the `*.csv` here.
2. `uv run scripts/project1_volume_yoy_chart.py` to redraw the PNG.
3. Re-diff against the repo: Project 1 feature tables (`PROJECT1/*-desktop-features.csv`,
   deduped on `id`, spam dropped) and aaq-scraper day-files
   (`aaq-data/<year>/questions-thunderbird-desktop-*.csv`, dedup on `id`).

## Caveats when comparing
- aaq-scraper `is_spam` is **not populated pre-2026**, so the scraper column
  includes a little unfiltered spam for old months (BQ uses `is_spam = FALSE`).
- Naively summing scraper day-files double-counts (cumulative snapshots) — dedup
  on `id`.
- Keep product/locale scope and created-date (UTC) bucketing identical across
  sources or months drift.
